# Couverture des 96 cas Squash

La découverte Playwright liste 96 références. Cela ne signifie pas 96 tests exécutables.
Les scénarios ne sont pas encore validés dans un navigateur : le lancement de Chromium est bloqué dans l’environnement de préparation. Les quatre tests de rattachement API passent sur API simulée. L’API Squash réelle reste à vérifier.
