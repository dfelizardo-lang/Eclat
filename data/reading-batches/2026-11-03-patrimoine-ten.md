# Collection patrimoniale : dix romans

Extension du lot ae189d94d6c2a7f89d34c417a8618ef2690bfbbf : dix romans, quinze extraits chacun, soit 150 extraits. Le conte Point de lendemain conserve ses trois extraits et reste hors de ce compteur.

Les paragraphes proviennent des éditions françaises historiques indiquées dans le catalogue. Les sélections sont non graphiques, sans réécriture, et respectent la limite de 2 000 caractères, espaces compris. Les genres sont précisés : cette collection comprend aussi des romans de la passion et de l'indépendance, sans les présenter tous comme des romans érotiques. Les coordonnées, révisions et empreintes sources sont consignées dans le fichier JSON de ce lot.

Précisions bibliographiques : Mademoiselle de Maupin est daté de 1835 ; l'édition du Lys dans la vallée est de 1868 malgré le nom du fichier de numérisation comportant 1874. La Vagabonde, dans son édition française originale, est entrée dans le domaine public en France en 2025 (Colette, morte en 1954).

Le catalogue général reste inchangé : 184 œuvres, 548 lectures. Les six extraits patrimoniaux antérieurs et les 554 identités de narration précédentes sont conservés. L'extension ajoute 147 textes, soit 294 nouveaux fichiers vocaux ; le manifeste attendu contient 701 textes avec deux voix chacun.

Validation locale : 68 tests réussis, aucun échec. Les romans sont repliables ; les extraits et lecteurs audio restent accessibles volontairement dans la collection adulte distincte. Les vérifications HTTP et audio publiques doivent être effectuées après le déploiement.
